# Commit 🚀

**Commit** is a platform that connects students with internships, workshops, hackathons, and other opportunities that match their skills, experience, and interests.

## 🎓 For Students

Students can create a profile and add:

* CV / Resume
* Academic information
* Certificates
* Skills
* Projects
* Experience
* LinkedIn
* Endorsements
* Interests

Commit uses this information to recommend opportunities that are a good match for each student.

## 🏢 For Companies

Companies and organizations can:

* Create a profile
* Post internships, workshops, and hackathons
* Add requirements and desired skills
* View applicants
* Find students who match their opportunity

## 🔗 How It Works


Student Profile
      ↓
Commit Matching System
      ↓
Relevant Opportunities
```

and


Company Opportunity
      ↓
Commit Matching System
      ↓
Relevant Applicants
```

## 🎯 Goal

The goal of Commit is simple:

**Help students find opportunities that fit them, and help companies find students that fit their opportunities.**

**Commit to your future. 🚀**
